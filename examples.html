This section provides examples of the use of this vocabulary, showing how verified preferences can be expressed as Verifiable Credentials issued by trusted third parties.

The first example shows a VerifiedPreferencesCredential issued by an email provider, attesting that the email address belongs to the subject. 

{
  "@context": [
    "https://www.w3.org/ns/credentials/v2",
    "https://w3id.org/preferences/v1"
  ],
  "type": ["VerifiableCredential", "VerifiedPreferencesCredential"],
  "issuer": "https://emailprovider.example/issuer",
  "validFrom": "2025-03-15T10:22:00Z",
  "credentialSubject": {
    "email": "jane.doe@example.com"
  }
}
